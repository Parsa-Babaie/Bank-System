# Bank System (C++)

A console-based bank management system written in C++ using OOP principles.

## Features
- Create accounts
- Show all accounts
- Check balance
- Deposit / Withdraw money
- Transfer money between accounts
- Persistent storage (save/load accounts to/from file)
- Input validation

## How to build
```bash
g++ main.cpp Bank.cpp account.cpp -o bank
./bank
```

## Tech
C++, OOP (classes, encapsulation), file I/O
